# Sentiment Analysis and Churn Prediction

## Project Overview

This Final Year Project presents a hybrid NLP-based system for sentiment analysis and customer churn prediction in e-commerce platforms.

The system combines Natural Language Processing (NLP), TF-IDF feature extraction, machine learning models, and a heterogeneous stacking ensemble to analyze customer reviews and predict customer behavior.

## Objectives

- Perform sentiment analysis on customer reviews.
- Extract meaningful textual features using TF-IDF.
- Predict potential customer churn.
- Combine multiple machine learning models using a stacking ensemble.
- Provide a web-based interface for making predictions.
